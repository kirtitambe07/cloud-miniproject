Secure Cloud Storage

Block-based encrypted file storage, hosted on a CDN

About the project

This mini-project splits a file into fixed-size blocks, encrypts each block with AES (Fernet), and lets a user download the file in encrypted form. This documentation site is hosted on cloud storage and delivered through a CDN over HTTPS.

How it works

  1. The user uploads a file through the Flask web app.
  2. The file is divided into 1 MB blocks.
  3. Each block is encrypted with Fernet (AES-128 and HMAC-SHA256).
  4. The encrypted blocks are stored and offered as a download.
  5. With the key, the blocks are decrypted and merged back into the original file.
  6. A SHA-256 hash comparison confirms the rebuilt file is identical.
